# Apex FPL project status

**Status date:** 7 August 2026

## Current state

The GitHub implementation has reached a production-green initial-squad standard for 2026/27.

Validated current capabilities:

- Official FPL API is the canonical source for player ID, club, FPL position, price, availability and fixtures.
- Immutable Official FPL snapshot manifests and checksums are recorded.
- FPL Core Insights enriches current player statistics, preseason data, Elo fixture context and defensive-contribution features.
- FPL Core data is resolved through an immutable commit and an automated refresh workflow keeps the pin current.
- Genuine AIrsenal GW1–GW8 forecasts are generated by the exact pinned upstream worker, exported through `player.fpl_api_id`, provenance checked and freshness gated.
- Apex expected-minutes modelling produces start, appearance, 60+, 80+, expected-minutes and confidence estimates.
- Tactical roles are inferred from involvement data and can be overridden by verified evidence.
- Penalty/corner/direct-free-kick/indirect-free-kick shares support both Official FPL order priors and verified overrides.
- Fixture difficulty blends Official FPL team strength, home/away context and reconciled FPL Core Elo.
- Transparent xP decomposition covers appearance, attack, clean sheets, defensive contributions, saves, 2026/27 bonus/BPS potential and set pieces.
- The ensemble reports expert disagreement, uncertainty, floors/ceilings and risk-adjusted xP rather than a blind single estimate.
- Legal mathematical optimisation supports unrestricted, Haaland-locked and no-Haaland initial structures.
- Current-squad multi-GW optimisation supports transfers, bank, 1–5 free transfers, hits, XI, captain/vice and fixed Wildcard/Bench Boost/Triple Captain planning.
- Trusted news evidence is classified for injury/availability, transfer and manager/line-up risk without being allowed to overwrite official identity.
- The independent pinned `open-fpl-solver` worker receives the same official-ID Apex projections as a robustness check.
- Fresh validation produced exact parity: 15/15 squad, 11/11 XI and the same captain.
- Unit/integration/regression tests and Ruff validation pass on current `main`.
- A fresh live run produced `safe_to_act=true` and `full_apex_ready=true`.
