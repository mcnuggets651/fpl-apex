# Generated Apex outputs

## User-facing source of truth
Only these files represent the Apex team recommendation:

- `apex_recommendation_latest.json`
- `apex_recommendation_latest.md`

They are generated by `scripts/run_apex.py` and the **Apex Unified** workflow.

## Internal / legacy files
Any of the following, when present, must **not** be treated as separate Apex recommendations:

- `pinnacle_latest.*` — internal maximum-EV/readiness/robustness diagnostic.
- `elite_latest.*` — internal epsilon/Elite diagnostic.
- `apex_latest.*` — legacy pre-unification published base snapshot.
- `solver_parity.*` — independent optimisation diagnostic.
- `airsenal.*` — projection-worker input/output.
- calibration/history outputs — learning diagnostics.

The canonical selector consumes internal diagnostics and emits exactly one team. If `apex_recommendation_latest.json` is absent or has `ready_to_act=false`, there is no current Apex recommendation to act on.
