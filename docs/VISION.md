# Apex FPL — Vision

## North star
Apex should become a continuously refreshed, auditable FPL decision system that is stronger than following any single public projection model, optimiser or pundit source.

## What “best” means
Not the most complicated model. The best system is the one that repeatedly makes stronger pre-deadline decisions under uncertainty while remaining reproducible and explainable.

## Apex 10
- validated multi-source projection stack
- Pinnacle maximum EV
- Elite ceiling-aware utility
- robust minutes/captaincy/set-piece/DEFCON handling
- stochastic downside/regret checks
- independent solver parity
- personal-team and receding-horizon workflow
- no-hindsight evaluation
- persistent project brain

## Apex 11 — richer probability layer
Potential focus:
- market-implied probabilities
- Bayesian minutes/start/60/90 distributions
- DEFCON threshold probabilities
- bonus/BPS simulation
- richer match simulation

## Apex 12 — adaptive season intelligence
Potential focus:
- calibrated ensemble weights from accumulated no-hindsight evidence
- ownership/EO and rank-context game theory
- price movement/value-growth model
- improved chip opportunity-cost forecasts

## Meta vision
A future Meta layer may compare specialised candidate engines, but it should remain transparent. It should explain why one candidate wins, what raw xP it gives up, and which uncertainty dimension justifies that trade.

## Human interface
The preferred interface remains conversation. The user should be able to ask “Give me the Apex team” and receive a current, source-validated, benchmarked answer without re-explaining the architecture.
