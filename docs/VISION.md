# Apex FPL — Vision

## North star
Apex should be a continuously refreshed, auditable FPL decision system that is stronger than blindly following any single public projection model, optimiser or pundit source.

That does **not** require an unqualified ensemble. Production should use the best currently justified authority and continuously challenge it with frozen independent alternatives.

## What “best” means
Not the most complicated model. The best system repeatedly makes stronger pre-deadline decisions under uncertainty while remaining reproducible, explainable and honest about evidence limits.

## Current Apex
- Official FPL factual authority;
- AIrsenal production statistical xP authority;
- Apex proprietary xP and external alternatives as shadow challengers;
- sealed DecisionBundle/provenance;
- exact legal maximum-EV decision mechanics;
- current-state receding-horizon transfers;
- captain/vice/bench/autosub mechanics;
- CVaR/regret/parity diagnostics;
- current football evidence with provenance;
- one user-facing answer contract;
- prospective learning/promotion governance.

## Next maturity layer — empirical provider qualification
Before adding more architecture, make the season-learning loop real:

- freeze every production/shadow forecast before deadlines;
- store immutable provider/version/snapshot/player/GW rows;
- attach Official outcomes later;
- compare AIrsenal, Apex shadow and future challengers by calibration/ranking/error/cohort and decision impact;
- promote only after the predeclared evidence bar is met.

## Richer probability layer
Potential later focus, only if it proves value:

- validated market-implied probabilities;
- Bayesian minutes/start/appearance distributions;
- DEFCON threshold probabilities;
- bonus/BPS simulation;
- richer correlated match simulation;
- price-change timing for option value.

## Adaptive season intelligence
Longer-term possibilities:

- prospectively learned provider/ensemble weights if evidence supports them;
- explicit rank-context/ownership utility separate from pure maximum points;
- improved chip opportunity-cost forecasts;
- qualified V2 control-plane/release authority once rebased on the current forecast contract.

## Human interface
Conversation remains the preferred interface. The user should be able to ask “Give me the Apex team” and receive either one current source-validated actionable answer or a concise explanation of why the gates correctly withhold it—without re-explaining architecture or accidentally receiving a historical squad.
