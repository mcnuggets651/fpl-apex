# Apex FPL — Charter

## Mission
Build the strongest publicly reproducible FPL decision engine we can defend with current facts, qualified forecasts and exact game mechanics.

## Standard
Apex exists to improve decisions, not to manufacture certainty. It should maximise expected FPL return while exposing assumptions, uncertainty, opportunity cost, evidence and provenance.

## Rules
1. Official FPL is canonical for current factual truth.
2. Production forecast authority must be explicit. Current statistical xP authority is AIrsenal; alternative providers remain challengers until promoted.
3. Never confuse one current production provider with permanent truth: maintain independent shadow/challenger evidence and judge it prospectively.
4. Never optimise value alone.
5. Never force premiums by reputation alone.
6. Expected minutes and role uncertainty must be represented in forecasts/evidence rather than hidden subjective selection preferences.
7. Captaincy, bench and autosubs are exact FPL decision mechanics, not afterthoughts.
8. Every recommendation must be legal, reproducible, sealed and auditable.
9. Every material model/provider change must be benchmarked on frozen no-hindsight evidence.
10. A failed/stale readiness gate stops an Apex-labelled recommendation.
11. Separate facts, forecasts, enrichment, diagnostics and selection authority.
12. Prefer one clear final action over contradictory model teams.
13. Never rewrite weights or named-player assumptions until a preferred squad appears.

## Success criterion
Over a meaningful genuine prospective sample, Apex should make stronger pre-deadline decisions than simpler baselines while maintaining transparent provenance and operational reliability.

## What Apex is not
- a guarantee of FPL rank;
- a generic web-tip aggregator;
- a popularity contest;
- a points-per-million spreadsheet;
- an excuse to make optional data sources hard blockers;
- an excuse to promote a proprietary model before it has earned evidence;
- an excuse to add complexity without measurable predictive/decision value.
